El Desafío

La sucursal de Tigo requería un sistema de fachada de alto rendimiento capaz de soportar cargas térmicas intensas manteniendo una transparencia visual absoluta. El mandato arquitectónico fue estricto: minimizar el entramado estructural visible para crear un efecto de vidrio suspendido sin costuras que se alineara con su identidad de marca vanguardista.

Además, el aislamiento acústico era primordial para las particiones de vidrio interiores a fin de garantizar la privacidad del cliente dentro del entorno corporativo de planta abierta, lo que requirió ingeniería acústica de precisión y unidades de acristalamiento especializadas.

La Respuesta

Precision Arch proyectó un sistema de muro cortina con acristalamiento estructural a medida utilizando vidrio templado de baja emisividad (Low-E). Nuestro equipo técnico desarrolló una subestructura de aluminio extruido con rotura de puente térmico, diseñada específicamente para permanecer completamente oculta desde el exterior.

Para el interior, instalamos nuestro sistema patentado de mamparas de doble vidriado con láminas acústicas de alto índice STC. Cada unión y aplicación de silicona estructural se ejecutó con precisión milimétrica, logrando una integración impecable entre el rendimiento técnico y la pureza arquitectónica.
